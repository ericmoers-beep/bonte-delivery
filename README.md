# Bonté Delivery Companion

Phone-friendly delivery route manager for Bonté Bakery.

## Features
- Pre-loaded route templates with all stops, addresses & delivery notes
- Delivery order ↔ Load order toggle (reverse for van loading)
- Per-stop invoice calculator with quantity adjustment tracking
- Pizza crust count logging
- Bread returns with product dropdown
- Daily notes per stop
- Address links open in Maps for navigation
- CSV export for Google Sheets
- Standard ops checklist
- Works offline (PWA with service worker)

## Deploy to GitHub Pages

1. Create a new repo on GitHub (e.g., `bonte-delivery`)
2. Upload all files from this folder to the repo
3. Go to **Settings → Pages**
4. Under "Source", select **Deploy from a branch**
5. Select **main** branch, root folder
6. Click Save
7. Your app will be live at `https://yourusername.github.io/bonte-delivery/`

## Add to iPhone Home Screen

1. Open the URL in Safari
2. Tap the Share button (square with arrow)
3. Tap "Add to Home Screen"
4. The app will run fullscreen like a native app and work offline
